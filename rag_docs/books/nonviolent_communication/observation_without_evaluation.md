# Observation Without Evaluation

## Core idea
The first component of NVC is to separate observation from evaluation. You should clearly describe the specific behaviors or conditions you see, hear, or touch without mixing in any judgment or analysis
When we combine the two, others are more likely to hear criticism and resist our message
Using process language that is specific to time and context (e.g., "In the last three meetings, you didn't speak") is more effective than using static generalizations (e.g., "You never participate")

## Use in EchoRole
Use this card when a user needs help slowing down the conflict, naming what is happening, and choosing a more constructive communication move.

## Suggested move
Help the user translate emotional reaction into a specific, observable, and actionable response.

## Avoid
- Treating this card as a fixed script.
- Giving the user a single correct answer.
- Ignoring the role, relationship type, and current turn situation.
