# Making Action Requests

## Core idea
The fourth component is requesting concrete actions that would enrich our lives. A clear request should use positive action language—stating what we want rather than what we don't want—and avoid vague or abstract phrasing
For example, instead of asking for "respect," ask for a specific action like "Would you be willing to knock before entering my office?"
It is also essential to distinguish requests from demands; a request is genuine if we stay empathic when the other person says "no"

## Use in EchoRole
Use this card when a user needs help slowing down the conflict, naming what is happening, and choosing a more constructive communication move.

## Suggested move
Help the user translate emotional reaction into a specific, observable, and actionable response.

## Avoid
- Treating this card as a fixed script.
- Giving the user a single correct answer.
- Ignoring the role, relationship type, and current turn situation.
