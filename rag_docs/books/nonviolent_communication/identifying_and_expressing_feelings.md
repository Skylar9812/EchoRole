# Identifying and Expressing Feelings

## Core idea
The second component is expressing how we feel. NVC distinguishes between actual feelings (emotions or sensations like "sad," "excited," or "scared") and thoughts, assessments, or interpretations of others
Statements like "I feel ignored" are interpretations of others' behavior rather than expressions of our own internal state
By building a rich vocabulary for feelings and allowing ourselves to be vulnerable, we can connect more easily and resolve conflicts

## Use in EchoRole
Use this card when a user needs help slowing down the conflict, naming what is happening, and choosing a more constructive communication move.

## Suggested move
Help the user translate emotional reaction into a specific, observable, and actionable response.

## Avoid
- Treating this card as a fixed script.
- Giving the user a single correct answer.
- Ignoring the role, relationship type, and current turn situation.
