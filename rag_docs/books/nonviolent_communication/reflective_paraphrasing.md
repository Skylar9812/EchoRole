# Reflective Paraphrasing

## Core idea
After listening empathically, we can reflect back what we have understood by paraphrasing the other person's observations, feelings, needs, or requests
This should be done in the form of a question to invite corrections (e.g., "Are you feeling hurt because you need more recognition?")
Paraphrasing confirms to the speaker that they have been heard, saves time in negotiations, and helps defuse intense emotions

## Use in EchoRole
Use this card when a user needs help slowing down the conflict, naming what is happening, and choosing a more constructive communication move.

## Suggested move
Help the user translate emotional reaction into a specific, observable, and actionable response.

## Avoid
- Treating this card as a fixed script.
- Giving the user a single correct answer.
- Ignoring the role, relationship type, and current turn situation.
