# Self-Compassion (Self-Empathy)

## Core idea
NVC is most transformational when applied to ourselves. When we make mistakes, we should replace moralistic self-judgment with "NVC mourning" (connecting with the unmet needs and feelings behind the regret) and "self-forgiveness" (connecting with the need we were trying to meet when we took the action)
We can also cultivate self-compassion by translating internal "have-to's" and "should's" into "choose-to's," recognizing that every action we take is in service of a need

## Use in EchoRole
Use this card when a user needs help slowing down the conflict, naming what is happening, and choosing a more constructive communication move.

## Suggested move
Help the user translate emotional reaction into a specific, observable, and actionable response.

## Avoid
- Treating this card as a fixed script.
- Giving the user a single correct answer.
- Ignoring the role, relationship type, and current turn situation.
