# EchoRole Next.js boundary

Minimal Next.js App Router + TypeScript application. No product redesign, UI framework, authentication, or session workflow is included.

```powershell
cd frontend
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Start FastAPI separately using `backend/README.md`. Open `http://127.0.0.1:3000`. The page reports whether its server-side health request to FastAPI succeeds. If the API is unavailable, the page still renders with an unavailable status; it does not substitute mock application data.

`ECHOROLE_API_URL` is server-only and defaults to `http://127.0.0.1:8000`. No Python modules, database files, or API credentials are imported into the frontend. The API helper uses a three-second timeout and disables caching for the health request. No browser-to-FastAPI calls or CORS configuration are introduced in this phase.

```powershell
npm run build
npm run typecheck
npm start
```

Node.js requirements and App Router conventions follow the [Next.js installation documentation](https://nextjs.org/docs/app/getting-started/installation). Dependency versions are recorded in this directory's package manifest and lockfile. `next-env.d.ts` and `.next/` are generated by Next.js and ignored.
